Scope: public product site for sintr at sintr.tiagomoraes.cloud, single page `site/index.html`. Mode: Persuade.

Audience: people in regular therapy who already run a file-capable AI agent daily. Job: understand in seconds what sintr is (a skill + a Markdown ledger, not an app, not an AI therapist), trust its privacy model, and install it into their agent. Proof on hand: the real entry/check-in formats from SKILL.md and the fictional example report in docs/example-report.md (Portuguese, shown with an EN toggle). Constraints: white ground, black CTAs, soft sky/sage/lavender/peach used sparingly, organic SVG, slow motion, reduced-motion + no-JS safe, vanilla static, English copy, install methods only from docs/INSTALL.md.

## Direction contract

THESIS: The page is the white wall of a quiet consulting room; window light crosses it as the week between two sessions passes. Refuses the wellness-app default (pastel blob hero, phone mockup, feature-card trio) and the dev-tool default (dark terminal page).

OWN-WORLD: White plaster ground, graphite ink, black pill buttons. Light is the only colour: a skewed 2×3 window (the brand glyph is its 2×2 detail) of soft gradient (sky, peach, lavender, sage) with blurred sage leaf shadows. Editorial light serif display (Source Serif 4), quiet grotesk body (Hanken Grotesk), mono only for real file contents (Fragment Mono). Ledger artifacts are white paper cards with a hairline edge and their file path as label. Hierarchy by type size and line breaks only: no icon tiles, no feature cards, no eyebrows.

STORY: Visitor learns the therapist sees 50 minutes of a 10,080-minute week; follows one fictional week (Tue capture, Thu check-in, Sun report, Mon session) through real file formats; reads the privacy model; copies an install command or prompt; leaves knowing sintr documents and professionals treat.

FIRST VIEWPORT: Nav (serif wordmark left; How it works, Privacy, Install, GitHub; black Install pill). Left 7 columns: three-line serif headline at ~5.6rem, lede, black "Copy install prompt" button plus agent list. Right: window light with swaying leaf shadows falls across the wall; one entry card rests in the light showing a verbatim quoted thought. Upper-right wall left deliberately empty.

FORM: Grounded candidate 4 of 7 (the consulting room at the session hour), seed key 8a15cc9c. Raises: festival-lineup (type size alone carries hierarchy), HyperCard (artifacts are real selectable files labelled by path), darkroom (report lifecycle draft→reviewed→approved→sent, approval the one irreversible gate), accretion-disk (one wall region held empty). Signature interaction: the light changes time of day as sections pass (morning, dusk, evening, golden, moonlit night, dawn) and the entry card writes itself field by field.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
