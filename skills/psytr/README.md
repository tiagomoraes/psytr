# sintr skill

This directory is a standard `SKILL.md` folder: copy it as-is into any Hermes, Claude Code, OpenCode, or OpenClaw skills directory and it will be discovered natively. It's also uploadable as a zipped skill in Claude Cowork, and readable by any other agent as a plain instruction pack. See [`../../../docs/INSTALL.md`](../../../docs/INSTALL.md) for per-agent paths.

Canonical file: [`SKILL.md`](SKILL.md).

For templates, use [`../templates/sintr`](../templates/sintr). The copy under `templates/sintr/` inside this skill exists so the installed skill can seed a fresh ledger on its own.
